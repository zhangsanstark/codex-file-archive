# EP04 故事方法测试包

## 项目目标

- 系列：《从〈金字塔原理〉学结构化表达》
- EP04 标题方向：高手表达的第一步：先给答案
- 目标认知：问题明确、信息足够、表达者已经形成判断时，第一句话先回答问题；理由负责支撑答案，不应迫使听众替表达者猜答案。
- 可迁移动作：对准问题 → 一句作答 → 理由跟上。

## 实验锁定条件

三版必须保持：

- 相同的目标知识、课程范围和迁移动作；
- 相近的口播时长和汉字数；
- 相同的结尾教学段及迁移示例；
- 不引入 MECE、条件护栏、信息不足或不确定性处理；
- 不把失败归因于胆怯、逃责、能力不足、没准备、坏人或技术事故。

V1、V2 的故事内对照还必须保持：

- 人物、事实、决定、权限、环境和总说话时长不变；
- 错误版和正确版使用逐字相同的答案段、理由段；
- 唯一变化是答案段在理由段之前或之后；
- 正确版不得补充新事实、改强语气或缩短说明。

## 共用教学收束

> 这里没有少讲一个事实，也没有缩短说明。变化只有一个：答案从最后，到了最前面。
>
> 问题明确、信息足够、你已经形成判断时，第一句话先回答问题。理由负责支撑答案，不该让对方替你猜答案。
>
> 记住三个动作：对准问题，一句作答，理由跟上。
>
> 比如有人问：“明天能上线吗？”
>
> 先说：“能。”
>
> 再说：“昨晚又测了一轮，三个核心流程都过了；剩下两处只是文案修改，不影响上线。”

## 盲测办法

不要向测试者透露版本身份。将 V0、V1、V2 随机改名为甲、乙、丙；每位测试者第一轮只接触一个版本，避免前一版泄露课程答案。

使用 [盲测记录表](盲测记录表.md) 收集：

1. 主课开放式复述；
2. 新问题的迁移改写；
3. 印象最深的画面或内容；
4. “像培训教材”的感受评分；
5. 继续观看系列的意愿。

暂定通过线：

- 至少 80% 的测试者首先复述“先回答问题”；
- 至少 70% 能在迁移题中先给明确答案，再给理由；
- 竞争课程复述率低于 20%；
- 故事版的继续观看意愿高于 V0，才能证明故事产生了实际增益。

竞争课程编码：

- V1：如果主要记住“删除重复内容”或“剪辑要果断”，记录为剪辑旁课；
- V2：如果主要记住“接戏要仔细”或“别让团队等”，记录为连续性/效率旁课；
- 任一版本：如果主要记住“少说废话”，记录为简洁旁课。
