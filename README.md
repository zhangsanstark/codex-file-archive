## 后续上传规则

- 使用上传当天的日期；当天新增上传继续使用下一个编号，新日期从第一次开始。
- 一个上传请求对应一个批次；单个文件夹的内容直接放入批次内。一次上传多个独立文件夹时，在批次内保留各文件夹名称。
- 已有批次保留；新增材料或修改版通常形成新批次。用户明确指定更新旧文件时按要求处理。
- 每次新上传同步更新本索引。目录整理本身不计入新的材料上传批次。
- 历史材料按原上传顺序重新整理，正文保持不变；旧路径可在整理前的 Git 提交中查看。
