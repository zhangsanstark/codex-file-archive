已补充风险，并更新了流程。**最大的调整是：样片直接按正片需求制作，复杂测试只在剧情需要时追加。**

这几类坑还要提前挡住：

| 容易漏掉的坑优化办法         |                                   |
| ------------------ | --------------------------------- |
| 删掉旁白，却让人物把心理活动全说出来 | 用挽袖、回看机器、继续剥蒜、主动坐下表达变化，避免对白变成讲解   |
| 测试片通过了，却不能用于正片     | 小样就使用最终台词、本集服装、真实场景和道具数量；合格后直接采用  |
| 把声音留到最后处理          | 分镜里标明机器低响、声音变化、完成提示音，以及人物何时反应     |
| 每段单看合理，剪起来时间和物态冲突  | 提前统一“二十多分钟如何过去”、衣物脱水程度、碗的位置和数量    |
| 只看首尾图、抽帧就判合格       | 完整带声播放，再检查口型、手物接触和切点；短暂错误可能落在采样间隙 |
| 只统计已扣费，忽略未出账任务     | 在途、结果未知、已完成未结算的任务都预留额度，避免并发超支     |

声音尤其不能假定后期一定能救。官方指南也列出了“禁止配乐仍出现音乐”，以及分离人声时同时移除音效的情况。[官方说明](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)

优化后的顺序是：

1. **先排文字节奏稿。** 用已有图或占位卡确认无旁白也能看懂。
2. **确认接口、声音路线和预算。** 尤其确认严格首帧与固定声线能否同时使用。
3. **只做首批需要的首帧。** 已接受的素材直接复用，不先铺完整集。
4. **生成两条正片对白并立即试剪。** 通过后保留为正片候选。
5. **按需追加难点，再每批做 2–4 镜。** 正反打够用就不另做双人对白；拿碗后能切剥蒜，就不强做跨段接续。
6. **逐批连看，最后核对导出。** 检查实际采用版本、漏镜、重复动作、声音和完整费用。

另保留两条停止规则：**每镜初抽后最多一次针对性修复；请求结果未知时先查原任务，禁止自动重新提交。** 改稿只标记受影响镜头复核，不自动重做整集。
