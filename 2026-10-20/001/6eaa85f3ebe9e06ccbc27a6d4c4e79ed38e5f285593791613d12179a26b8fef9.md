# 任务与用途
为中文母语的英语学习者制作考研单词助记。读者看到英文能联想到中文义，也能顺着故事还原全部字块、拼出整个单词。你自主设计拆分、记法和完整中文故事，我方只提供单词和本次中文义。只交一套定稿。

# 本次输入
目标词：{{word}}
中文义：{{meaning}}

# 全部单词共用的词块表 v0.1
这是通用知识，不是本词的预定拆分。你仍自主决定拆分，先确认确为本词适用的构词单位，再优先整体使用，不无故拆成几个字母道具。变体必须保留本词原拼写，不机械按字母串匹配。
- com / con / col / cor / co：共同、一起；部分词中是加强或完全，按本词实际用法核实，不统一译成“所有、全都”。
- re：再次；un：不，或取消、反向；pre：之前；post：之后。
- inter：之间；sub：下面；super：在上、超出；trans：跨越、横过。
- auto：自身；tele：远距离；semi：半；mis：错误地、不当地；non：非、不。
- less：后缀，没有、缺少；fort：历史词根，强、坚强，与独立熟词fort“堡垒”的记法分别标明。
只使用能确认适用的义项。本表不是这些成分的所有义项；表中没有的陌生词根不临时当作已知知识。读者使用该方案前，需先掌握所用整块的字母顺序和本次含义，prerequisites要列清楚。本表不能解释的剩余字块仍须全部交代。
构词单位用kind=morpheme；已知完整英文词仍用familiar_word，不混淆构词依据与故事虚构。词缀可体现为影响主要事件的属性、位置、角色关系或前后对照，不必强造道具；但不能只在无关紧要的“一起、又、不”等随口词上贴标签。不要为了套词根损害故事自然程度。

# 拆分与记法
1. 全部小写字块按顺序直接连接，必须精确等于目标词。每块都有清楚来路，不能漏掉难记的尾块，或把目标词本身当已会熟词。
2. 优先保留已会的完整英文词和上表中确实适用的构词单位，再考虑中文拼音、明确的谐音或简单字形联想。熟词写清已会词义和拼写的前提；拼音给出对应汉字的完整去声调拼写；谐音说明借哪种已知读音或字母音，别把谐音冒充准确拼音或目标词英语读音。不能靠另背陌生难词、无依据截取字母来补齐。
3. 字形只解释帮助认出字母的关键外形，不写成几何证明，不声称物件与每一笔完全一致。需要特定视角或大写转小写就简短说明，不能编不存在的笔画、方向或连接。
4. 字块用具体人物、动物、物件，或画面中清楚的属性、位置来记；共享构词单位也可按上节规则体现为实际关系或前后对照。不要把字块标在故事里的动词、心理活动或为字母摆出的动作姿势上，也别把动作改叫“做动作的人”规避。目标词本身可以是动词；故事动作正常串联事件。
5. 不用ta→他、ni→你、I/i→我等代词凑块；指明“他就是某名人”也不能让这种线索变得具体。正文可以正常使用代词，这条只限制拼写线索。
6. 这些线索要一起构成主要画面，不能只是顺路出现。尽量避免靠任意数量、随口语气词、泛泛的等级或弱修饰补字母，尤其不要连续几个块都如此。短字块有具体、鲜明的画面也可以好记，不按长度禁用。确实难拆时，来路和前提真实清楚、其余主要线索及词义联系强，可以保留少量较弱辅助块，但不能让弱线索成为主要记忆负担；不为加强它们另背难词或拉长故事。重复字块也要有可辨认的画面来路，不靠数几次。
7. 如果完整拆法始终牵强，就用input_issue说明卡点，跳过这词，不强造记法。

# 故事
用大众熟悉的人物，例如李白、张飞、苏轼、孙悟空、猪八戒等，具体人选由你决定。优先发挥其性格、习惯或本领；人物姓名参与字块时，也要让人能想起具体人物。这是新编助记，不是史实、原著情节或词源解释。

像给朋友讲一件事，用大白话、常见词、自然短句。简单易读，不追文笔。人物或物件的鲜明形象本身就可以是记忆点。可用短而熟悉的夸张形容、反差称呼、标志性外貌或装束，也可借用学习者熟悉的人物形象，让普通线索变得具体、有亮点。集中突出一两个特点，不要求这些描写另外推动剧情、造成后果或引出反转；大白话也可以夸张、生动，不必写得平淡。优先加强字块对应的人物或物件，这些描写不能替代字块本身完整、准确的来路。避免没有画面作用的冗长堆词，不强制每篇夸张或使用某个角色。故事的记忆点还可以来自意外后果、人物性格反差、出糗或自然笑点，按本词选择。主要字块要承载这些形象或参与事件，整体故事仍需帮助理解词义；不能只演示词义后重复“原来就是这个意思”，也不能在字块之后再追加一段无关笑话。只讲一件事，全部字块依次用“中文线索（字块）”标注。至少约一半故事围绕字块链，不计算标签字符比例来凑数。事件有可理解的动机或处境，以及由此发生的具体后果。目标词义要体现在这些关系里，尤其抽象词不能只靠开头说目的、结尾贴释义或几个角色同场；形象描写可以直接增强印象，不要求每一处形象或笑点都单独解释词义。成功、失败或出糗都可以，不额外讲大道理。事件本身能让人想到中文义；字块串完时主要事件也接近完成，随后短收尾。没有最低字数，能短而不漏必要线索与因果就短，不为解释字形堆长句。

定稿前检查完整拼接、每块来路、非动作及非代词线索、正文顺序和含义，并检查：记忆点是否写成具体画面；形象描写是否让对应线索更鲜明（无需另添事件后果）；是否用多个弱辅助块凑尾；事件是否真实表现本词义。note通常一句话，说明真实记法即可；不要输出评分、自夸或已验证记忆效果的保证。
